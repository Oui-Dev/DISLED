# Measurements

Results of the bring-up and tuning campaigns ([bringup.md](../bringup.md)):
one Markdown file per board, named after its serial number (for example
`3A1F00C2B4D5E6F708192A3B.md`), plus the CSV recordings exported from the
desktop app.

Phase 2 derives the tuned values of `firmware/src/app/app_config.c` from
these files; each tuned value should cite the measurement it comes from.
