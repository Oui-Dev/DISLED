# Changelog

Each part of DISLED is versioned and released separately, with its own
changelog ([docs/releasing.md](docs/releasing.md)). release-please writes
those of the firmware and the desktop app from the commit messages; those
of the hardware are written by hand:

- [firmware/CHANGELOG.md](firmware/CHANGELOG.md), tags `fw-vX.Y.Z`
- [app/CHANGELOG.md](app/CHANGELOG.md), tags `app-vX.Y.Z`
- [hardware/pcb/CHANGELOG.md](hardware/pcb/CHANGELOG.md), tags `pcb-vX.Y.Z`
- [hardware/enclosure/CHANGELOG.md](hardware/enclosure/CHANGELOG.md), tags
  `enclosure-vX.Y.Z`
